# 安心看

这是给一位视力较弱、阅读文字和操作手机不太方便的老人做的 Android 小应用。

普通手机上的日期和星期信息通常比较小，也比较分散。这个应用把星期、时间和日期放在首页，用大字显示；星期用数字 1–7 表示，方便快速确认当天是星期几。首页还提供天气信息。

## 功能

- 大字显示星期，用数字 1–7 表示，同时显示时间和日期。
- 根据手机位置显示三天天气，包括天气图形和最低、最高温度。
- 天气需要精确定位权限和网络；获取失败时，时钟仍然正常显示。

支持 Android 12 及以上。

使用 Kotlin + Jetpack Compose 开发，天气数据通过 Cloudflare Worker 从 Open-Meteo 获取。
