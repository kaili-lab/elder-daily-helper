# 安心看：备案与部署说明

## 当前结论

“安心看”可以不上架华为、小米、荣耀等手机应用商店，通过 APK 安装包分发。但安装来源不是 App 备案的判断条件，不上架应用商店不构成自动豁免。

如果 App 在中国境内正式提供，或面向测试用户提供天气查询、语音查询、语音播报或大语言模型服务，应按 105 号通知的规则先办理 App 备案，再提供相应的互联网信息服务。个人可以作为 App 主办者，通常不需要因为办理个人非经营性备案而先注册公司。

## 关键判断

判断是否需要考虑 App 备案，核心不是 APK 从哪里安装，而是 App 是否在中国境内提供互联网信息服务。

当前项目的在线功能包括：

- 天气查询；
- 语音查询；
- 语音播报；
- 大语言模型调用；
- 可能的用户设置或联系人同步。

这些功能已经超出纯离线 App 的范围。即使 App 只通过 APK 私下分发给几个人，也不能仅以“人数少”“不收费”或“不上架应用商店”为理由认定免备案。105 号通知没有为封闭小范围测试规定明确豁免；该测试是否落入具体监管边界，应以所在地通信管理部门或腾讯云给出的书面答复为准。

## 不同场景

| 场景 | 当前判断 |
| --- | --- |
| 纯离线原型，只显示本地时间、日期和星期 | 通常不涉及 App 互联网信息服务 |
| 只在自己的手机上测试，没有后端 | 没有明显的在线服务场景 |
| APK 私下分发给几个人，面向这些测试用户连接中国大陆服务器提供天气、语音和 LLM 服务 | APK 安装方式不构成豁免；如果这是面向测试用户提供在线服务，应按 105 号通知先办理 App 备案。若只是封闭开发测试，条文未明确是否落入具体备案边界，应以所在地通信管理部门或腾讯云书面答复为准 |
| 正式向更多用户提供在线服务 | 应先完成 App 备案 |
| 后端仅部署在中国香港或其他境外服务器 | 不涉及中国大陆服务器的 ICP 接入关系；但这不自动等于 App 永远免除其他备案判断 |
| App 上架应用商店 | 通常需要 App 备案，分发平台也可能要求备案信息 |

## 几种备案不是一回事

### App 备案

登记 App 主体、App 名称、Android 包名、签名指纹、使用域名等信息。它针对的是 App 提供互联网信息服务的情形。

### 网站 ICP 备案

如果另外提供公开网站、APK 下载页、管理后台或其他网站服务，并且使用中国大陆服务器，需要单独判断是否需要网站 ICP 备案。

### 中国大陆服务器的接入关系

如果后端部署在中国大陆云服务器上，需要通过云服务商处理 ICP 备案中的服务器、域名和接入关系。这里的“接入备案”通常是备案接入商侧的操作或接入关系，不应理解为与 ICP 备案完全独立、固定增加的一份备案。它也不能替代 App 备案。

### ICP 经营许可证

ICP 备案和 ICP 经营许可证不同。个人非经营性备案不等于 ICP 经营许可证。是否属于经营性互联网信息服务，要结合收费模式、服务对象和具体业务判断，不能仅因为 App 调用了 API 就直接断定需要许可证。

## 对本项目的建议

分两个阶段推进：

1. 先开发纯离线 Kotlin 原型，验证锁屏显示、大字时间、日期和星期，以及不同 Android 版本和手机厂商的限制。
2. 确定天气、语音和大语言模型功能后，再以个人主体向腾讯云和所在地通信管理部门确认具体备案要求，然后决定使用中国大陆服务器还是境外测试服务。

如果使用中国大陆腾讯云服务器，App 应使用固定域名，不要把服务器 IP 写死在 APK 中。服务器迁移时，需要维护域名、备案接入关系和 App 登记信息。

## 官方依据

- [工业和信息化部关于开展移动互联网应用程序备案工作的通知](https://www.gov.cn/zhengce/zhengceku/202308/content_6897341.htm)
  - 工信部信管〔2023〕105号。
  - 规定在中华人民共和国境内从事互联网信息服务的 App 主办者应履行备案手续。
  - App 主办者可以是组织或个人。
  - 通知没有把“不上架应用商店”或“只给几个人测试”列为自动豁免条件。

- [腾讯云首次备案流程](https://cloud.tencent.com/document/product/243/37402)
  - 支持选择“个人”作为备案主体。
  - 支持选择 APP 作为应用服务类型。
  - App 备案需要填写 App 名称、运行平台、域名、包名和 Android 签名 MD5 等信息。

- [腾讯云备案常见问题](https://cloud.tencent.com/document/faq/243/19629)
  - 更换云服务商或接入商时，通常需要在新的接入商处办理接入备案。

## 仍需确认的问题

- 以个人主体备案时，所在地省级通信管理部门对本项目语音、天气和大语言模型服务的具体要求。
- 腾讯云当前对个人 App 备案所需大陆云资源、账号类型和服务期限的要求。
- 纯内部封闭测试是否落入具体备案边界；官方条文没有规定明确豁免，最终以所在地通信管理部门或腾讯云书面答复为准。
- 境外后端和中国大陆正式服务两种部署方式分别适用哪些备案和接入流程。
- 语音服务和大语言模型服务是否还涉及其他专项合规要求。

本文是项目需求讨论记录，不是法律意见。正式部署前，应以工信部、所在地通信管理部门和云服务商的最新要求为准。
